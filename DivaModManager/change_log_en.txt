DivaMoaManager by Enomoto v1.3.1.34
  Changes (Please refer to GitHub for previous changes)

----- Known Issues and Limitations -------------------------
- The feature that moves folders into the Mods folder when dragged and dropped is currently disabled.
- Previously, if an alternative source file was found during Update, the download would proceed from the alternative source file. However, due to unification of processing logic, the operation will now be interrupted and the Mod page will be opened instead. This feature is planned to be reimplemented after further verification of the processing flow.
- Removed the display of the total size of the Mod folder.

----- Specification Changes -------------------------
- From the perspectives of security and related concerns, the following are now mandatory system requirements:
  - Windows 10 (Version 1809 or later) / 64-bit
  - .NET 10.0
      Runtime download: https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0
  (Note: Raising the required version has significantly increased the size of the executable file.)
- During Mod updates, the terminology has been changed to "Clean Update" to better reflect the actual behavior.
  (Note: This behavior has existed since the original DivaModManager. When Update is executed, almost all files inside the Mod folder are deleted regardless of whether they were generated by the application or not, and replaced with files from the new version. Please be careful.)
- Automatic registry registration at startup has been removed. Registration and removal of registry entries can now be performed manually from the Option tab.
  (Supplement: Registry registration is used for the one-click install feature.)
- The behavior that automatically downloaded and installed DivaModLoader on first launch has been revised. Please install it manually using the "Update Check" button at the top right.

----- Changes (Important) -------------------------
- Added Japanese localization support for some existing and newly implemented popup dialogs.
  Language settings can be configured on first launch.
- Added output of "config_e.toml" in the same folder as DivaModManager.exe, allowing advanced configuration such as language settings and duplicate Mod comparison targets.
  (Since this has been clearly separated from Config.json, manual editing of Config.json is generally discouraged.)
- If a configuration file exists but cannot be loaded at startup or similar situations, the original file will now be backed up and a new file generated automatically.
- Compression archive support has been limited to only "Zip", "7z", and "Rar".
- Bundled the console version of "7-Zip" (7z.exe) in compliance with its license.
- (Important) Only the bundled version of 7z.exe can be used, even if a newer version is available. Please note this carefully.
  The libraries used by the application have been comprehensively reviewed, with additions, removals, and updates performed.
  As part of this, license-related files are now included. Please review them if interested.
- Completely revised startup and setup checks so that the main window will not be displayed if the application is in an unexpected state.
- When the DivaModManager version changes, configuration files from the previous version are now automatically backed up.
- Temporarily implemented the Option tab.
  Added functionality in the Option tab to back up DivaModLoader and DivaModManager configuration files.
  (Note: There is no automatic restore function for backups. If a configuration file becomes corrupted, manual restoration such as renaming files will be required.)
- Significantly revised and unified extraction processing. Fixed issues involving conflicts when running multiple extraction processes simultaneously, and improved strictness of size checks and related validation.

----- Changes (High Priority) -------------------------
- An error will now be displayed if a Mod folder name contains Japanese characters.
- If another DivaModManager process exists at startup and is not responding, the process will now be terminated.
  Also fixed an issue where processes could remain after abnormal termination during startup.
- Added Debug Mode (please do not use under normal circumstances; primarily intended for trace log output during bug investigation).
  Run "DivaModManager_DebugMode.bat" to launch in Debug Mode. Logging output has also been comprehensively revised accordingly.
- The application will now terminate if an unrecoverable error occurs.
- Launch and Update Check operations are now disabled while background download processing is running.
- When displaying the Mod list, simple checks are now performed for issues such as duplicate folders or duplicate Mods.
  These checks can be individually enabled or disabled in config_e.toml located in the Mod folder or DMM folder.
- If loading configuration files such as Config.json or config.toml fails, the original file will now be backed up before overwriting.
- Added a Version column.
- Added a Site column.

----- Changes (Medium Priority) -------------------------
- Added an icon in the upper-right icon area to open the MM+ folder.
- For v0.0.14 and v0.0.16 only, the correct DivaModLoader version will now be displayed even if DivaModLoader was installed manually.
- Approximate file sizes are now displayed in download and update popups.
- Added descriptions of each parameter to "config_e.toml" in each Mod folder.
- Added "HomePage Open" to the context menu of the Mod list (references the "homepage" field in mod.json).

----- Changes (Low Priority) -------------------------
- Added tooltips to the Fetch Metadata text box so that input examples are displayed.

----- Other Changes -------------------------
- Performed extensive revisions to numerous minor issues beyond what can reasonably be listed.
- Performed extensive revisions to internal processing beyond what can reasonably be listed.
