DivaMoaManager by Enomoto v1.3.1.35 for Linux/Wine (alpha)

----- Notice (Please read carefully!!) -------------------------

- This executable is intended for users of Linux/Wine environments
  It has been heavily restricted from the Windows version DivaMoaManager by Enomoto v1.3.1.34.
  (There are no new features, so users of Windows do not need this version.)

- Use at your own risk
- Operation outside the [Verified Operating Environments] listed below has not been confirmed.
- Especially in Linux distributions that differ or environments like Steam OS (Steam Deck), there may be fatal bugs that render the OS non-functional.
  (If, by any chance, all features are usable in a Linux environment, the likelihood of fatal operation is very high, so please let us know.)
- If a directory containing symbolic links, etc., is provided, there may be fatal bugs causing malfunction or OS failure.

- Installing .NET is probably unnecessary (the executable size is very large instead).
- Since we prioritize implementing the same features as the Windows version, feature requests are generally not accepted.

----- Bugs and Feature Restrictions -------------------------

This version limits functionality as a Mod management tool for those who already have a fully built Mod operating environment.
Specifically, the following functions are disabled compared to the Windows version DivaMoaManager by Enomoto v1.3.1.34.

- Functions of tabs other than Manage Mods.
- The function to automatically download and place DivaModLoader at startup.
- Functions of the Setup, Launch, and Update Check buttons.
- Right-click Mod deletion functions, etc.
- Issues such as popup windows not becoming active or checkbox states in popup windows not reflecting, etc.

----- Verified Operating Environments -------------------------

- Linux Mint 22.3 (Zena)
- wine-9.0 (Ubuntu 9.0~repack-4build3)
