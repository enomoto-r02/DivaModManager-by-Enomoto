
DivaMoaManager by Enomoto v1.3.1.35 for Linux/Ubuntu/Steam Deck (alpha2)

----- Notice (Please read carefully!!) -------------------------

- This executable is intended for users of Linux Mint, Ubuntu, and Steam Deck environments.
  It has significantly reduced functionality compared to the Windows version DivaMoaManager by Enomoto v1.3.1.34.
  (There are no new features, so if you use Windows this version is unnecessary.)

- Use at your own risk.
- Operation outside of the [verified operating environments] listed below has not been confirmed.
- Especially on Linux distributions that differ or on Mac OS and similar environments, the OS may become non-functional.

- Installing .NET is probably unnecessary (the executable size is very large instead).
- We prioritize implementing features as close to the Windows version as possible, so feature requests are generally not accepted.

----- Bugs and Feature Restrictions -------------------------

This version limits functionality as a Mod management tool for users who already have a complete Mod operating environment.
Specifically, changes from the Windows version DivaMoaManager by Enomoto v1.3.1.34 include:

- Hiding functions of tabs other than Manage Mods
- Stopping automatic download and placement of DivaModLoader at startup
- Disabling Setup, Launch, and Update Check buttons
- Disabling right‑click Mod deletion functionality, etc.
- Popup windows do not become active; the state of popup window checkboxes is not reflected
- Adjusting minimum window size and message content to consider Steam Deck resolution
- Switching to fonts installed by default on the OS (temporary)
- Operations caused by cursor movement on devices like Steam Deck have not been confirmed.
