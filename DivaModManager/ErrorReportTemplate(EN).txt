This is an error reporting template.
Please fill in the information below and, if everything looks correct, paste it into Discord or another platform to report the error details to the developer.
For an example of how to fill out this template, please refer to "Error Report Template Example.txt" (it would be greatly appreciated if you could fill out as many fields as possible).

Please report the issue using one of the following methods (choose one):
1. Send a DM to @enomoto_r02 (Discord)
2. Post it in the "diva-help" channel or the "DivaModManager by Enomoto" thread within diva-threads on the Project DIVA Modding 2nd Discord server
3. Submit a report on the "DivaModManager by Enomoto" GameBanana page

[Important]
If you choose option 2 or 3, other users will be able to view this report.
While your report may help users experiencing the same issue, please be careful not to include personal information such as your username.
